## 当前结论

融合 MegaMoE 仍是最大 GPU 耗时项。256 并发 kernel 覆盖率98.6%，进一步减少 CPU 同步的空间有限；128 为91.1%，仍有间隙值得调查。覆盖率仅统计 kernel 时间并集，不包含 memcpy；间隙不等于全部由 CPU 导致。
